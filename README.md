# 인하공업전문대학 홈페이지 — 프론트엔드 프로토타입

화면정의서 v0.3 기준. 순수 HTML + CSS + JavaScript. 백엔드 없이 브라우저만으로 동작합니다.

## 실행

```bash
cd inhatc
python -m http.server 5500
# http://localhost:5500
```

## 화면 목록

| 파일 | 화면 | 비고 |
|---|---|---|
| `index.html` | SC-01 홈 | **기본** — 학사일정을 카드 클릭 시 모달로 |
| `index-split.html` | SC-01 홈 (비교용) | 홈을 반으로 나눠 달력을 함께 배치 |
| `notices.html` | SC-02 공지 목록 | 장학 하위 필터 포함 |
| `notice.html` | SC-03 공지 상세 | |
| `notice-form.html` | SC-04 작성 · 수정 | 관리자 전용 |
| `search.html` | SC-06 통합 검색 | |
| `page.html` | SC-07 학교 안내 | 문서 19개를 이 파일 하나로 |
| `calendar.html` | SC-09 학사일정 | 전체 화면 버전 |

**홈 화면이 두 개인 이유**는 학사일정 배치를 비교하기 위해서입니다. 팀에서 하나를 고른 뒤 나머지는 지우세요.

- `index.html` — 카드를 눌러 모달. 공지 영역이 넓게 유지됩니다
- `index-split.html` — 화면 분할. 달력이 항상 보이지만 공지가 반으로 줄어듭니다

## v0.2에서 바뀐 것

- 학교명을 인하공업전문대학으로 변경 (로고와 공지 내용은 직접 제작)
- 상단 메뉴에 **신포털** 추가 (외부 링크, 새 창)
- 홈 배너를 사진 한 장으로. 누르면 대학 안내로 이동
- **홈 공지 탭이 페이지 이동 없이 목록만 바꿉니다**
- 홈 바로가기 5칸 (생활관 추가, 외부 링크)
- **장학 하위 분류** (전체 · 근로 · 일반)
- **SC-09 학사일정 달력** — 월 이동, 중요 일정에 형광펜
- 챗봇이 화면별로 다르게 동작 (화면정의서 2-5)

## 챗봇 동작

우하단 **AI 도우미** → 추천 질문을 누르면 왼쪽 화면이 결과로 바뀝니다.

| 지금 화면 | 챗봇이 답하면 |
|---|---|
| 홈 · 공지 목록 | 그 자리에서 목록이 걸러짐 (이동 없음) |
| 상세 · 검색 · 안내 | "목록에서 결과 보기" 링크 표시 |
| 작성 · 수정 | 이동하지 않음 (쓰던 글 보호) |
| 학교와 무관한 질문 | 답변만 표시 |

## 백엔드 연결

`js/chat-engine.js`의 `chatAnswer()`를 `POST /api/chat` 호출로 바꾸면 됩니다.
응답 형태는 이미 같습니다 — `{ answer, action, sources }`.

공지 데이터는 `js/data.js`의 `window.NOTICES`를 `GET /api/notices` 응답으로 교체합니다.
`js/data.js`는 DB의 `seed.sql`과 같은 내용이라 값이 어긋나지 않습니다.

## 지켜야 할 규칙

- 색은 `css/tokens.css`에서만 정의합니다
- 포인트 3색은 역할이 정해져 있습니다 — cyan(AI·장학), red(마감·삭제), amber(행사·고정·형광펜)
- 사용자 입력값은 `innerHTML`이 아니라 `textContent` 또는 `esc()`를 씁니다
- 외부 링크는 `js/data.js`의 `window.EXTERNAL` 한 곳에만 주소를 적습니다

## 미구현 (의도적)

- 실제 인증 — 관리자 모드는 버튼을 보이고 숨기는 장치입니다
- 데이터 영속성 — 브라우저 탭 안에서만 유지됩니다
