# 한빛공업전문대학 홈페이지 — 프론트엔드 프로토타입

화면 정의서(v0.2)의 SC-01 ~ SC-08 을 순수 HTML + CSS + JavaScript 로 구현한 것입니다.
백엔드 없이 브라우저만으로 전부 동작하며, 실제 프로젝트의 화면 뼈대로 그대로 씁니다.

---

## 실행 방법

**로컬 서버로 여는 것을 권장합니다.**

```bash
cd hanbit
python -m http.server 5500
# 브라우저에서 http://localhost:5500 접속
```

파일을 직접 더블클릭해도(`file://`) 대부분 동작하지만, 브라우저에 따라
데이터 저장이 막힐 수 있습니다. VS Code 를 쓴다면 Live Server 확장이 가장 편합니다.

## 챗봇이 핵심입니다

이 프로젝트의 평가 기준은 **"챗봇이 답할 때 목록이 눈에 띄게 바뀌는가"** 입니다.

공지 목록 화면에서 오른쪽 아래 **AI 도우미** 를 누르고 추천 질문을 눌러 보세요.

1. 오른쪽에서 패널이 열리고 **본문이 왼쪽으로 밀립니다** (덮지 않습니다)
2. 답변이 나오는 동시에 **목록이 30건 → 4건으로 줄어듭니다**
3. 카테고리 탭도 함께 이동하고, 목록 위에 조건 칩이 뜹니다
4. 답변 아래 근거 공지 카드를 누르면 상세로 이동합니다

## 백엔드 연결 방법

지금은 `js/chat-engine.js` 안의 `window.chatAnswer()` 가 답변을 만듭니다.
백엔드가 준비되면 이 함수만 fetch 로 바꾸면 됩니다. **응답의 모양은 이미 같습니다.**

```js
// 지금 (목업)
var res = window.chatAnswer(text);

// 나중 (백엔드)
var res = await fetch(API + "/api/chat", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ message: text, history: [] })
}).then(r => r.json());
```

응답 형식:

```json
{
  "answer": "이번 주 마감인 장학 공지는 3건입니다.",
  "action": { "type": "filter", "category": "장학", "keyword": null, "dueBefore": "2026-08-17", "noticeId": null },
  "sources": [ { "id": 30, "title": "...", "department": "...", "dueDate": "..." } ]
}
```

공지 API도 마찬가지로 `js/data.js` 의 `window.NOTICES` 를 `GET /api/notices` 응답으로 바꾸면 됩니다.

## 지켜야 할 규칙

- **색상은 `css/tokens.css` 에서만 정의합니다.** 다른 파일에 hex 값을 직접 쓰지 마세요.
- **포인트 3색은 역할이 정해져 있습니다.** cyan = AI·장학, red = 마감·삭제, amber = 행사·고정.
  아무 데나 쓰면 챗봇이 눈에 띄지 않습니다.
- **사용자가 입력한 값은 `innerHTML` 로 넣지 않습니다.** `textContent` 또는 `esc()` 를 씁니다.
  글쓰기 기능이 있으므로 이건 실제 위험입니다. `notice.js` 의 본문 렌더링을 참고하세요.
- **React, Tailwind, 빌드 도구를 추가하지 않습니다.** 순수 HTML/CSS/JS 만 씁니다.

## 아직 안 된 것 (의도적으로 생략)

- **실제 인증**: 관리자 모드는 화면에서 버튼을 보이고 숨기는 장치일 뿐입니다.
  서버가 붙으면 쓰기 API 에 최소한의 키 검증을 추가해야 합니다.
- **데이터 영속성**: 브라우저 탭 안에서만 유지됩니다. 탭을 닫으면 초기 30건으로 돌아갑니다.
  관리자 모드 상단 바의 '데이터 초기화' 로 직접 되돌릴 수도 있습니다.
- **파일 첨부, 댓글, 로그인**: 화면 정의서 1-1 의 '추가 개발' 항목입니다.
