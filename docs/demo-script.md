# 3분 시연 영상 — 대본과 촬영 순서

**링크** `https://smpsws.shop`

> **자동 녹화도 됩니다.** `docs/record_demo.py` 가 이 대본대로 브라우저를 조작하며
> 화면을 녹화합니다 (자막 포함, 약 2분). 직접 찍기 전에 한 번 돌려 보면
> 흐름을 눈으로 확인할 수 있습니다. 사용법은 파일 맨 위에 있습니다.
>
> 다만 **무음**이고 **주소창이 안 잡힙니다.** 아래 0:10 구간(링크 붙여넣기)은
> 기준 3의 증거라 직접 찍어 앞에 붙이는 편이 좋습니다.

심사 기준 3가지 중 **2번(새 기능이 실제로 동작)이 이 프로젝트의 전부**입니다.
그래서 3분 중 **1분 30초를 챗봇에** 씁니다. 나머지는 최대한 짧게 지나갑니다.

---

## 녹화 전 체크리스트

순서대로 하세요. 특히 ★ 는 영상 품질을 크게 좌우합니다.

- [ ] **★ 캐시 데우기** — 녹화 직전에 시연할 질문 4개를 한 번씩 던져 둡니다.
      캐시가 비어 있으면 OpenAI 왕복 때문에 질문마다 2~5초씩 멈춥니다.
      한 번 던져 두면 **즉답**이라 영상이 훨씬 매끄럽습니다.
- [ ] 배포 상태 확인 — `bash db/deploy/checksite.sh https://smpsws.shop`
      → **통과 20 · 실패 0** 이어야 녹화를 시작합니다
- [ ] **시크릿 창**으로 엽니다 — 확장 프로그램·자동완성·로그인 흔적이 안 나옵니다.
      "설치도 로그인도 필요 없다"는 것을 보여 주는 장면이기도 합니다
- [ ] 브라우저 확대 **110~125%** — 작은 화면으로 볼 심사위원도 글자가 읽힙니다
- [ ] 북마크바 숨기기 (`Ctrl+Shift+B`), 알림·메신저 끄기
- [ ] 녹화 도구 — Windows 는 `Win+G` 게임바로 충분합니다. 1080p 권장

캐시 데우기는 이 명령 하나로도 됩니다.

```bash
for q in "이번 주 마감인 장학금 알려줘" "근로장학금 공고 있어?" \
         "취업 관련 공지 보여줘" "기숙사 얘기 있어?"; do
  curl -s -X POST https://smpsws.shop/api/chat \
       -H 'Content-Type: application/json' \
       -d "{\"message\": \"$q\"}" > /dev/null
  echo "데움: $q"
done
```

## 대본

말할 내용은 **그대로 읽어도 되게** 썼습니다. 편하게 바꾸셔도 됩니다.

### 0:00 – 0:10 · 티저 (말 없이, 자막만)

| | |
|---|---|
| 화면 | 공지 목록에서 AI 도우미를 열고 **`이번 주 마감인 장학금 알려줘`** 클릭 |
| 보여줄 것 | 왼쪽 목록의 **총 71건 → 총 N건** 숫자가 바뀌는 순간 |
| 주의 | '이번 주 마감'은 **오늘 날짜로 계산**돼 건수가 날마다 다릅니다. 대본에 숫자를 외워 두지 말고 화면에 나온 값을 읽으세요 |
| 자막 | `말로 물어보면, 화면이 바뀝니다` |

**해설 없이 동작만** 보여줍니다. 첫 10초에 핵심을 못 보여주면 나머지를 안 봅니다.
목록 건수가 바뀌는 부분을 잠깐 확대하거나 화살표를 넣으면 더 좋습니다.

### 0:10 – 0:25 · 링크 하나로 실행

| | |
|---|---|
| 화면 | 시크릿 창을 새로 열고 주소창에 링크를 **붙여넣고 엔터** → 홈이 뜸 |
| 말할 것 | "인하공업전문대학 홈페이지에 AI 공지 도우미를 붙였습니다. 링크 하나면 되고, 설치도 로그인도 없습니다." |

주소창에 링크를 **직접 붙여넣는 장면**을 꼭 담으세요. 기준 3의 증거입니다.

### 0:25 – 0:45 · 기본 흐름

| | |
|---|---|
| 화면 | 홈 → 상단 **공지사항** → 목록에서 아무 공지 **클릭** → 상세 → 뒤로 |
| 말할 것 | "공지 71건, 학사일정 33건, 안내 문서 20건이 들어 있습니다. 데이터는 MySQL 에 있고, 화면은 API 로 받아옵니다." |

빠르게 지나갑니다. 여기서 시간을 쓰면 안 됩니다.

### 0:45 – 2:15 · ★ 챗봇 (가장 중요)

**공지 목록 화면에서** 시작하세요. 목록이 바뀌는 게 바로 보입니다.

#### ① 0:45 – 1:15 — 여러 조건이 겹친 질문

| | |
|---|---|
| 클릭 | AI 도우미 → **`이번 주 마감인 장학금 알려줘`** |
| 보여줄 것 | ⓐ 답변 ⓑ **71 → 몇 건으로** ⓒ 카테고리 탭이 **장학**으로 이동 ⓓ 마감 조건 칩 ⓔ 근거 카드 3장 |
| 말할 것 | "'이번 주'와 '장학금', 두 조건이 겹쳤습니다. 답변만 하는 게 아니라 **화면을 대신 조작합니다.** 탭이 장학으로 옮겨졌고, 마감 조건이 칩으로 붙었고, 목록이 확 줄었습니다." |

**여기서 3~4초 멈추세요.** 심사위원이 숫자와 칩을 읽을 시간이 필요합니다.

#### ② 1:15 – 1:30 — 근거 확인

| | |
|---|---|
| 클릭 | 답변 아래 **근거 카드 하나를 클릭** → 상세로 이동 → 뒤로 |
| 말할 것 | "답변 아래에 근거가 붙습니다. 누르면 실제 공지로 갑니다. **지어낸 말이 아닌지 바로 확인할 수 있습니다.**" |

#### ③ 1:30 – 1:50 — 다른 방식의 질문 두 개

| | |
|---|---|
| 클릭 | **`근로장학금 공고 있어?`** → 하위 필터 + 6건 |
| 클릭 | **`기숙사 얘기 있어?`** → 키워드 검색 + 2건 |
| 말할 것 | "'근로'라고 하면 하위 분류까지 좁힙니다. '기숙사'처럼 카테고리에 없는 말은 키워드로 찾습니다. **학생이 쓰는 일상 표현을 그대로 받습니다.**" |

#### ④ 1:50 – 2:15 — 범위 밖 질문과 원리

| | |
|---|---|
| 입력 | 직접 타이핑 — **`오늘 점심 뭐 먹지?`** |
| 보여줄 것 | 답만 나오고 **목록은 그대로 71건** |
| 말할 것 | "학교와 무관한 질문에는 화면을 건드리지 않습니다. 이게 가능한 이유는, **AI 가 부르는 함수의 인자가 곧 화면 조작 명령**이기 때문입니다. 답변 문장을 파싱하는 게 아니라, 구조화된 값을 그대로 씁니다. 그래서 표현이 달라져도 흔들리지 않습니다." |

목록 건수가 **안 바뀌는 것**을 보여주는 게 포인트입니다.

### 2:15 – 2:35 · 나머지 화면

| | |
|---|---|
| 화면 | 학사일정 달력 (월 넘기기, 형광펜 표시) → 통합 검색에 아무 단어 |
| 말할 것 | "학사일정은 달력으로, 검색은 공지와 안내 문서를 함께 찾습니다." |

### 2:35 – 3:00 · 구조와 안전장치

| | |
|---|---|
| 화면 | README 의 구조도를 띄우거나, 슬라이드 한 장 |
| 말할 것 | "정적 파일과 API 를 nginx 한 대에서 서빙합니다. 그래서 링크가 하나입니다. **그리고 2단으로 막아 뒀습니다.** OpenAI 가 죽으면 규칙 기반 엔진이 같은 형식으로 답하고, API 서버까지 죽으면 브라우저가 목업 데이터로 화면을 그립니다. **시연 도중 외부 서비스가 멈춰도 챗봇이 멈추지 않습니다.**" |
