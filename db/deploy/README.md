# DB 서버 반영 스크립트

「DB 서버 반영 작업 지시서」 2부를 그대로 스크립트로 옮긴 것입니다.
**로컬 컴퓨터에서** 번호 순서대로 실행하세요.

## 준비

```bash
cd db/deploy
cp config.env.example config.env
```

`config.env` 를 열어 아래를 채웁니다.

| 항목 | 확인 방법 |
|---|---|
| `SERVER_IP` | Lightsail 콘솔 > 인스턴스 |
| `SSH_KEY` | Lightsail 콘솔 > 계정 > SSH 키 |
| `SSH_USER` | Ubuntu 이미지는 보통 `ubuntu` |

**비밀번호는 어느 파일에도 적지 않습니다.** 스크립트가 그때그때 물어보거나 직접 생성합니다.
`config.env` 와 `*.pem` 은 `.gitignore` 에 등록돼 있습니다.

## 실행 순서

| 스크립트 | 지시서 | 하는 일 | 서버 변경 |
|---|---|---|---|
| `00-check-file.sh` | 단계 0 | 덤프 파일 종류·문자셋·테이블 확인 | 없음 |
| `01-check-server.sh` | 단계 1~2 | 접속·디스크·메모리·MySQL 버전·sql_mode·기본 문자셋·기존 DB | 없음 |
| `02-upload.sh` | 단계 3 | 스왑(필요시) + scp 전송 + 체크섬 검증 | 파일만 |
| `03-backup.sh` | 단계 4 | 기존 DB 백업 | 없음 |
| `04-import.sh` | 단계 5 | utf8mb4 로 임포트 | **DB 생성** |
| `05-verify.sh` | 단계 6 | 검증 쿼리 8개 | 없음 |
| `06-appuser.sh` | 단계 7 | 앱 전용 계정 생성 + 비밀번호 발급 | **계정 생성** |
| `07-network.sh` | 단계 8 ①② | bind-address, 시간대, ufw | **설정 변경** |
| `08-test-remote.sh` | 단계 9 | 로컬에서 원격 접속 테스트 | 없음 |

`00` `01` `05` `08` 은 읽기만 하므로 몇 번을 돌려도 안전합니다.
서버를 바꾸는 `02` `04` `06` `07` 은 실행 전에 물어봅니다.

## 안전 규칙

스크립트에 그대로 박아 넣은 제약입니다.

- 키 파일 경로와 비밀번호를 어떤 파일에도 쓰지 않습니다
- `root` 를 `'%'` 로 열지 않습니다 — `06` 이 확인까지 합니다
- 3306 을 `0.0.0.0/0` 으로 열지 않습니다 — `07` 이 내 IP 로만 제한합니다
- 기존 DB 를 백업 없이 `DROP` 하지 않습니다 — `04` 가 백업 파일 존재를 확인합니다
- 서버를 바꾸는 단계마다 확인을 받습니다

## 지금 넣는 덤프에 대해

`db/dump_from_team.sql` 은 팀원이 만든 **스키마 초안 + 더미 5건** 입니다.
`05-verify.sh` 의 아래 항목이 설계서 기준과 다르게 나오는 것이 정상입니다.

| 항목 | 설계서 | 이 덤프 |
|---|---|---|
| 테이블 | 4개 (`chat_cache` 포함) | 3개 |
| 건수 | 66 / 33 / 19 | 5 / 5 / 5 |
| 장학 하위 분류 | 근로 6 · 일반 11 | 국가장학 1 |
| `CHECK` 제약 | 있음 | 없음 |
| 문자셋 선언 | `utf8mb4` | **없음** (서버 기본값 상속) |
| DB 이름 | `inhatc` | `mini_project` |
| 챗봇 시연 데이터 | 장학 4건 · 기숙사 2건 | **0건** |

**지금은 서버 파이프라인을 뚫는 것이 목적**이고, 스키마와 seed 교체는 다음 작업입니다.
`01-check-server.sh` 가 서버 기본 문자셋을 확인하므로, `utf8mb4` 로 나오면
파일을 고치지 않고 그대로 넣어도 한글은 깨지지 않습니다.

## 끝난 뒤

`06` 이 출력한 `DATABASE_URL` 을 FastAPI 의 `.env` 에 넣습니다.
`?charset=utf8mb4` 를 빼면 한글이 물음표로 나옵니다.

프로젝트가 끝나면 반드시 정리하세요.

```sql
DROP USER 'inhatc_app'@'%';
```

그리고 Lightsail 콘솔에서 3306 규칙을 삭제합니다.
