# 처음부터 따라 하는 DB 서버 구축 가이드

아무것도 없는 상태에서 **FastAPI 가 붙을 수 있는 MySQL 서버**까지 만드는 전체 절차입니다.
위에서부터 순서대로만 따라가면 됩니다.

- **총 소요 시간** 40분 ~ 1시간 (대부분 설치 대기)
- **필요한 것** AWS 계정, 인터넷, 터미널
- **미리 알아야 할 것** 없습니다. 명령어는 전부 복사해서 붙여넣으면 됩니다

---

## 전체 그림

```
[A] AWS 콘솔에서 서버 만들기          15분   ← 웹 브라우저
        │
[B] 내 컴퓨터 준비                     5분   ← 터미널
        │
[C] 스크립트로 서버 구축              20분   ← 터미널 (00 ~ 09)
        │
[D] 백엔드 연결 정보 정리              5분
        ▼
   FastAPI 개발 시작
```

`[C]` 는 번호 순서대로 스크립트를 돌리기만 하면 됩니다.
각 스크립트가 무엇을 할지 먼저 보여주고 **물어본 뒤에** 실행합니다.
`y` 를 누르지 않으면 서버는 바뀌지 않습니다.

# [A] AWS 콘솔에서 서버 만들기

> 이미 Lightsail 인스턴스가 있고 IP 와 키 파일을 갖고 있다면 **[B] 로 건너뛰세요.**

## A-1. 인스턴스 생성

1. https://lightsail.aws.amazon.com 접속
2. **[인스턴스 생성]** 클릭
3. 아래대로 고릅니다

| 항목 | 선택 |
|---|---|
| 리전 | **서울 (ap-northeast-2)** |
| 플랫폼 | **Linux/Unix** |
| 블루프린트 | **OS 전용** → **Ubuntu 22.04 LTS** |
| 요금제 | **1GB RAM / $5** 권장 |

**블루프린트에서 "앱 + OS" 를 고르지 마세요.**
WordPress·LAMP 같은 이미지는 MySQL 이 다른 경로에 깔려 있어서 이 스크립트가 맞지 않습니다.
반드시 **OS 전용(OS Only)** 입니다.

요금제는 512MB 짜리를 골라도 동작합니다. 스크립트가 스왑을 만들어 주긴 하지만,
설치가 느리고 가끔 실패합니다. **1GB 를 권합니다.**

4. 인스턴스 이름을 정하고 (예: `inhatc-db`) **[인스턴스 생성]**
5. 상태가 **"실행 중"** 이 될 때까지 1~2분 기다립니다

## A-2. 고정 IP 붙이기 ★ 건너뛰지 마세요

기본 IP 는 **인스턴스를 껐다 켜면 바뀝니다.**
IP 가 바뀌면 `.env` 의 접속 주소도, Lightsail 방화벽 규칙도 전부 다시 해야 합니다.

1. 인스턴스 클릭 → **[네트워킹]** 탭
2. **[고정 IP 연결]** → **[고정 IP 생성]**
3. 이름을 정하고 **[생성]**

화면에 뜬 IP 를 적어둡니다. 이게 앞으로 쓸 **서버 IP** 입니다.

```
서버 IP: _______________________
```

## A-3. SSH 키 내려받기

1. Lightsail 콘솔 우측 상단 **계정** → **[계정]**
2. **[SSH 키]** 탭
3. 서울 리전의 기본 키 옆 **[다운로드]**
4. `LightsailDefaultKey-ap-northeast-2.pem` 같은 파일이 받아집니다

**이 파일이 서버의 열쇠입니다.**
GitHub 에 올리거나 카톡·메일로 보내지 마세요. 이 파일만 있으면 누구나 서버에 들어옵니다.

받은 위치를 적어둡니다.

```
키 파일 경로: _______________________
```

### Windows 사용자는 WSL 을 쓰세요

이 스크립트는 리눅스/맥용입니다. Windows 는 **WSL(Ubuntu)** 에서 돌리는 게 가장 확실합니다.

PowerShell 을 **관리자 권한으로** 열고:

```powershell
wsl --install
```

설치 후 재부팅하고, 시작 메뉴에서 **Ubuntu** 를 실행합니다. 이후는 리눅스와 똑같습니다.

**키 파일을 WSL 안으로 옮겨야 합니다.** Windows 폴더(`/mnt/c/...`)에 두면
권한 설정(`chmod 400`)이 먹지 않아 접속이 거부됩니다.

```bash
mkdir -p ~/keys
cp /mnt/c/Users/내이름/Downloads/LightsailDefaultKey-ap-northeast-2.pem ~/keys/
chmod 400 ~/keys/LightsailDefaultKey-ap-northeast-2.pem
```

이제 키 파일 경로는 `~/keys/LightsailDefaultKey-ap-northeast-2.pem` 입니다.

> Git Bash 로도 되긴 하지만 `.pem` 권한 문제가 자주 생깁니다. WSL 을 권합니다.

## 3단계 · MySQL 설치 ★ 가장 오래 걸립니다

```bash
./02-install-mysql.sh
```

빈 서버를 쓸 수 있는 MySQL 로 만듭니다. **5~10분 걸립니다. 중간에 끄지 마세요.**

순서대로 이렇게 진행됩니다.

```
① 스왑 만들기      메모리가 부족할 때만
② MySQL 설치       apt-get install mysql-server
③ 문자셋 고정      utf8mb4 + 한국 시간대     ← 한글이 걸린 부분
④ 보안 설정        익명 사용자·test DB 제거, root 원격 차단
⑤ 검증             버전 8.0.16 이상인지, sql_mode 확인
```

중간에 세 번 정도 **`y` 를 물어봅니다.** 전부 `y` 로 답하면 됩니다.

<details>
<summary>③ 문자셋 고정이 왜 중요한가</summary>

팀원 덤프에는 `CHARSET` 선언이 없습니다.
그래서 테이블이 **서버 기본값**으로 만들어지는데, 이건 테이블을 만드는 순간 정해지고
나중에 고치려면 데이터를 다 지우고 다시 넣어야 합니다.

지금 서버 기본값을 `utf8mb4` 로 못 박아두면
**덤프 파일을 한 글자도 안 고쳐도** 한글이 안 깨집니다.
</details>

<details>
<summary>④ root 비밀번호를 왜 안 물어보는가</summary>

Ubuntu 의 MySQL 은 root 를 `auth_socket` 방식으로 만듭니다.
비밀번호 대신 **"서버에 `sudo` 로 로그인한 사람인지"** 를 보고 통과시킵니다.

- 유출될 비밀번호가 애초에 없습니다
- 네트워크로 root 접속하는 방법이 아예 없습니다

지시서의 "root 비밀번호 설정" 보다 안전해서 이대로 둡니다.
</details>

**끝나면 이게 나와야 합니다.**

```
   OK character_set_server = utf8mb4
   OK root 는 서버 내부에서만 접속 가능합니다
   OK 8.0.16 이상 → CHECK 제약 사용 가능
   OK MySQL 준비 완료.
```

<details>
<summary>❌ 설치가 중간에 멈추거나 실패한다면</summary>

거의 항상 **메모리 부족**입니다.

```bash
ssh -i ~/keys/키파일.pem ubuntu@서버IP "free -m; df -h /"
```

`Mem` 의 total 이 500 근처면 512MB 인스턴스입니다.
스크립트가 스왑을 만들었는지 확인하고, 그래도 안 되면 **다시 실행해 보세요.**
apt 는 중단된 지점부터 이어서 진행합니다.

계속 실패하면 Lightsail 콘솔에서 인스턴스 요금제를 1GB 로 올리는 게 확실합니다.
</details>


**세 군데를 다 열어야 접속됩니다. 하나만 빠져도 안 됩니다.**

```
① MySQL 설정 (bind-address)     ← 스크립트가 함
② 서버 방화벽 (ufw)              ← 스크립트가 함
③ Lightsail 콘솔 방화벽          ← 직접 해야 함
```

스크립트가 ①② 를 하고, 마지막에 ③ 을 안내하며 **내 공인 IP 를 알려줍니다.**

### ③ 은 웹 브라우저에서 직접 하세요

1. Lightsail 콘솔 → 인스턴스 → **[네트워킹]** 탭
2. IPv4 방화벽 → **[규칙 추가]**
3. 애플리케이션 **`MySQL/Aurora`**, 포트 **`3306`**
4. **★ "IP 주소로 제한" 을 켜고** 스크립트가 알려준 IP 를 넣습니다
5. **[생성]**

**"IP 주소로 제한" 을 반드시 켜세요.**
3306 을 전체 공개하면 **몇 시간 안에 자동 로그인 시도가 들어옵니다.**
실제로 며칠 안에 뚫립니다.

> **카페나 학교 와이파이는 IP 가 자주 바뀝니다.**
> 어제까지 되던 접속이 갑자기 timeout 이면 십중팔구 내 IP 가 바뀐 것입니다.
> `curl -s ifconfig.me` 로 지금 IP 를 확인하고 콘솔 규칙을 고치세요.
> 다른 사람이 붙어야 한다면 그 사람의 IP 를 규칙에 추가하면 됩니다.
